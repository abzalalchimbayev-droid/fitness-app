# План похудения — PWA-приложение

Программа тренировок (круговой формат), секундомер для планки, история подходов и веса с выгрузкой в CSV.
Работает офлайн, устанавливается на телефон как приложение. Данные хранятся только в браузере телефона.

## Файлы

- `index.html` — приложение
- `manifest.json` — описание приложения (имя, иконки, цвета)
- `sw.js` — офлайн-кэш
- `icons/` — иконки

## Публикация на GitHub Pages (один раз)

1. Зайдите на github.com → **New repository**. Название, например, `fitness-app`. Тип: **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**, перетащите **все файлы и папку `icons`** из архива (сам `index.html` должен лежать в корне репозитория). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)**. Нажмите **Save**.
5. Через 1–2 минуты вверху страницы появится адрес вида `https://ВАШ-ЛОГИН.github.io/fitness-app/`.

## Установка на телефон

- **Android (Chrome):** откройте адрес → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
- **iPhone (Safari):** откройте адрес → кнопка «Поделиться» → **На экран «Домой»**.

После этого иконка появится как у обычного приложения, открывается без адресной строки и работает без интернета.

## Обновление приложения

1. Замените `index.html` в репозитории (Add file → Upload files, либо иконка карандаша).
2. В файле `sw.js` увеличьте номер версии: `const CACHE = 'fitness-v2';` — иначе телефон покажет старую версию из кэша.
3. Подождите минуту, закройте и снова откройте приложение.

## Важно

- История и вес хранятся локально в браузере телефона. Если очистить данные сайта или удалить приложение — они пропадут. Периодически нажимайте **«Выгрузить историю (CSV)»**.
- Данные с разных устройств не синхронизируются.
